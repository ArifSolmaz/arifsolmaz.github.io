# GitHub Eğitimi — uygulamalı atölye paketi

Bu klasör, öğrencilere ve çalışma arkadaşlarına GitHub kullanımını uygulamalı
öğretmek için hazırlanmış kısa bir eğitim paketidir. Amaç, katılımcıların ilk
günden bir depoda düzenleme yapması, pull request açması, birbirinin işini
incelemesi ve küçük bir çakışmayı çözmesidir.

## Kime uygun?

- GitHub hesabı olan ama Git/GitHub iş akışına yeni başlayan öğrenciler
- Kurum içi belge, web sitesi, veri veya proje takibi için GitHub kullanacak ekipler
- Komut satırına hazır olmayan ama ortak çalışmayı öğrenmesi gereken kişiler

İlk atölyede komut satırı zorunlu değildir. Katılımcılar GitHub web arayüzüyle
başlar; ikinci oturumda GitHub Desktop veya terminale geçilebilir.

## Önerilen süre

**Kısa atölye:** 2 saat  
**Rahat atölye:** 3 saat  
**İki oturumlu eğitim:** 2 saat + 2 saat

## Dosyalar

- [egitmen-rehberi.md](egitmen-rehberi.md): dersi yürüten kişi için hazırlık ve akış
- [katilimci-el-kitabi.md](katilimci-el-kitabi.md): katılımcılara verilecek adım adım not
- [alistirmalar.md](alistirmalar.md): sınıf içinde yapılacak uygulamalar
- [slayt-iskeleti.md](slayt-iskeleti.md): sunum hazırlamak için başlıklar
- [degerlendirme-listesi.md](degerlendirme-listesi.md): katılımcıların kazanımlarını kontrol listesi
- [ornek-depo/](ornek-depo/): ayrı bir eğitim deposuna kopyalanabilecek başlangıç malzemesi

## Eğitimin ana fikri

GitHub önce bir ortak çalışma düzenidir:

- **Depo:** ortak proje klasörü
- **Commit:** kaydedilmiş kontrol noktası
- **Branch:** ana işi bozmadan çalışılan ayrı alan
- **Pull request:** değişikliği ekibe önerme ve tartışma alanı
- **Merge:** onaylanan değişikliği ana çalışmaya alma
- **Issue:** yapılacak iş, hata, soru veya karar kaydı

Katılımcılar bu kavramları sadece dinlememeli; her birini aynı oturumda
kendileri kullanmalıdır.

## Hızlı başlangıç

1. GitHub’da yeni bir özel veya herkese açık eğitim deposu oluşturun.
2. `ornek-depo/` içindeki dosyaları bu yeni depoya kopyalayın.
3. Katılımcıları depoya davet edin.
4. Atölyeyi [egitmen-rehberi.md](egitmen-rehberi.md) dosyasındaki akışla yürütün.
5. Ders sonunda [degerlendirme-listesi.md](degerlendirme-listesi.md) ile kazanımları kontrol edin.
