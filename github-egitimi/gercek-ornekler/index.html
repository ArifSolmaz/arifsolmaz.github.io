Repo bulunca

Beğendiğiniz projeyle ne yapılır?

Değerlendir

README, lisans, son release, son commit, açık issue'lar ve test durumuna bakın. Star tek başına güven ölçütü değildir.

Kaydet

Sonra dönmek için star verin; sürüm ve güvenlik duyurularını izlemek istiyorsanız Watch ayarını bilinçli kullanın.

Kullan

Önce dokümantasyondaki kurulum ve örnekleri izleyin. Kodu kendi projenize almadan önce lisansı okuyun ve kaynak gösterin.

İndir

Sadece bakacaksanız Code → Download ZIP yeter. Çalıştırıp güncelleyecekseniz GitHub Desktop veya git clone kullanın.

Geliştir

Yazma yetkiniz yoksa fork alın. Yeni branch açın, küçük bir değişiklik yapın, test edin ve açıklayıcı commit yazın.
