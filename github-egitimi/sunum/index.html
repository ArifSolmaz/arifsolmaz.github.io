3 · Pull request

Mekatronik Mühendisleri için GitHub

17

main, gerçek robotta çalışan sürümdür; bu yüzden onun üzerinde deneme yapılmaz. Bunun yerine bir branch açarsınız: rahatça değişiklik yapabileceğiniz ayrı bir kopya. Değişikliğiniz çalışınca, onun main'e katılması için bir pull request açarsınız. Bir takım arkadaşı inceler, sonra birleştirilir (merge). Deneme başarısız olursa branch'i silersiniz; main'e hiç dokunulmamıştır. Learn Git Branching'in branch ve merge seviyeleri bunu büyüyen bir ağaç olarak gösterir.

Mekatronik Mühendisleri için GitHub

18

Diff, bir dosyanın iki sürümü arasında tam olarak neyin değiştiğini gösterir. Başında − olan kırmızı satırlar silinmiş, başında + olan yeşil satırlar eklenmiştir; gri satırlar değişmemiştir ve sadece bağlam için oradadır. Diff'i her pull request'te (Files changed sekmesi) ve her commit'te görürsünüz. Bir değişikliği kabul etmeden önce diff'i mutlaka okuyun, kendi değişikliğiniz olsa bile.

Review (inceleme), birinin pull request'ini okuyup birleştirilmeden önce geri bildirim vermektir. İyi yorum kibar ve somuttur, bir satırı gösterir ve nedenini açıklar. 2. BÖLÜM · İŞ BİRLİĞİ

Merge conflict: panik yok

// firmware/main.ino

<<<<<<< HEAD

const float Kp = 1.4;

=======

const float Kp = 1.8;

>>>>>>> feature/pid-ayar

Ne oldu? İki kişi aynı satırı farklı değiştirdi; Git hangisinin doğru olduğuna karar veremez.

1 · Hangi değer doğru? Takımla konuşun ya da robotta test edin.

2 · İşaretleri silin, doğru satırı bırakın.

3 · Kaydedin, commit edin, push edin.

Önlem: sık sık pull, küçük branch'ler, aynı dosyada aynı anda çalışmamak.

Mekatronik Mühendisleri için GitHub

20

Merge conflict (çakışma), iki kişi aynı satırı farklı şekilde değiştirdiğinde olur. Git hangisinin doğru olduğunu tahmin edemez; ikisini de gösterir ve sizden seçmenizi ister. HEAD altındaki kısım sizin sürümünüz, ======= altındaki kısım diğeridir. Doğru satırı bırakın, işaret satırlarını (<<<, ===, >>>) silin ve kaydedin. Bu bir hata değil, sadece bir sorudur. Pratik için GitHub Skills'in kısa ve ücretsiz Resolve merge conflicts kursunu yapabilirsiniz.
