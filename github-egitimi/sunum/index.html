KARAR ÖLÇÜTÜ

Git gerekli mi?

Git her dosya için şart değil. Ama geçmiş, ekip çalışması veya güvenli deneme gerekiyorsa erken başlamak büyük rahatlık sağlar.

Kullanın

Kod, rapor, devre şeması veya analiz dosyası değişecekse ve eski hale dönmek istiyorsanız.

Şart değil

Tek seferlik, atılacak bir dosya için Git kurmak öğrenme yükü yaratabilir.

Dikkat

Şifre, API anahtarı, kişisel veri ve büyük ham dosyalar doğrudan depoya girmez.

Soru şu değil: “Git biliyor muyuz?” Soru şu: “Bu işte geçmiş, ortak çalışma ve güvenli deneme gerekiyor mu?”

GIT

Bilgisayarınızdaki araç

  • Dosyalardaki her değişikliği izler
  • Geri sarılabilir tam bir geçmiş tutar

Buluttaki web sitesi

  • Repolarınızı çevrimiçi barındırır
  • Issue, pull request, proje panoları
  • Takımınız için erişim kontrolü
  • İşlerinizin herkese açık portfolyosu

Bu kayıtlar için ortak bir albüm gibi.

GERÇEK KULLANIM

feature/servo-fix

Push ile çalışma ekip arkadaşlarının görebileceği yere gider.

git push

Pull request'te diff okunur, yorum yapılır, gerekirse değişiklik istenir.

Files changed

6 · Birleştir / geri dön

Uygunsa merge edilir; yanlışsa revert ile geçmiş silinmeden geri alınır.

merge veya revert
