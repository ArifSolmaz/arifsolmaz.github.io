Dersin akışıLesson plan

  1. Temeller: dosya sorunu, Git ve GitHub ayrımı, depo, commit, README
  2. Kayıt akışı: hazırlık alanı, yerel geçmiş, push ve pull
  3. Takım çalışması: issue, branch, pull request, inceleme ve çakışma
  4. Paylaşım: kütüphane seçimi, lisans, fork, portfolyo ve öğrenci imkânları
  5. Ekler: kurulum, SSH ve ayrıntılı komutlar, ana ders süresinin dışında
  6. Foundations: file versions, Git and GitHub, repository, commit, README
  7. Saving changes: staging, local history, push and pull
  8. Teamwork: issues, branches, pull requests, reviews and conflicts
  9. Sharing: libraries, licenses, forks, portfolios and student benefits
  10. Appendix: installation, SSH and detailed commands outside the main lecture
