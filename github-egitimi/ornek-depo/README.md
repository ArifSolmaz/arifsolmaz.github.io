# GitHub Eğitim Deposu

Bu depo, GitHub kullanımını uygulamalı öğrenmek için hazırlanmıştır.

Bugün şunları yapacağız:

- kendi katılımcı dosyamızı ekleyeceğiz
- branch oluşturacağız
- pull request açacağız
- başka bir pull request’i inceleyeceğiz
- küçük bir çakışmayı çözeceğiz

## Başlangıç görevi

1. `katilimcilar/` klasörüne gidin.
2. Kendi adınızla yeni bir `.md` dosyası oluşturun.
3. Aşağıdaki şablonu doldurun.
4. Değişikliği yeni bir branch’te kaydedin.
5. Pull request açın.

```md
# Ad Soyad

- İlgi alanım:
- GitHub’dan beklentim:
- Bugün öğrendiğim ilk kavram:
```

## Çalışma kuralları

- Küçük değişiklikler yapın.
- Commit mesajınızı anlaşılır yazın.
- Pull request açıklamasını boş bırakmayın.
- Başkasının çalışmasına yorum yaparken somut ve nazik olun.
