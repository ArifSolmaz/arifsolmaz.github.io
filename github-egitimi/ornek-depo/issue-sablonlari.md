# Issue şablonları

Eğitimden önce bu başlıklarla issue açabilirsiniz.

## Katılımcı profilini ekle

```md
Katilimcilar klasörüne kendi adınla bir profil dosyası ekle.

Tamamlanma ölçütü:
- Dosya `katilimcilar/ad-soyad.md` biçiminde
- İçerikte en az üç madde var
- Pull request açıldı
```

## README’ye kaynak önerisi ekle

```md
README dosyasına GitHub öğrenmek isteyenler için bir kaynak bağlantısı ekle.

Tamamlanma ölçütü:
- Bağlantı çalışıyor
- Kaynağın ne işe yaradığı bir cümleyle açıklandı
```

## Proje notlarında yazım hatası düzelt

```md
`proje-notlari.md` dosyasında küçük bir yazım veya ifade düzeltmesi yap.

Tamamlanma ölçütü:
- Değişiklik küçük ve anlaşılır
- Commit mesajı neyin düzeldiğini söylüyor
```

## Çakışma alıştırması

```md
Eğitmen söylediğinde `cakisma-alani.md` dosyasındaki aynı satırı düzenle.

Tamamlanma ölçütü:
- Değişiklik branch üzerinde yapıldı
- Pull request açıldı
- Çakışma oluşursa birlikte çözüldü
```
