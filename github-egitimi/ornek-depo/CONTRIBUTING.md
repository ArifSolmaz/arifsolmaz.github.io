# Katkı rehberi

Bu eğitim deposunda katkı akışı şöyledir:

1. Size atanmış issue’yu okuyun.
2. Değişikliğinizi yeni bir branch’te yapın.
3. Açık bir commit mesajı yazın.
4. Pull request açın.
5. En az bir arkadaşınızdan review isteyin.
6. Onaydan sonra merge edin.

## Pull request açıklama şablonu

```md
## Ne değişti?

## Neden?

## Kontrol listesi
- [ ] Dosya doğru yerde
- [ ] Yazım hatası kontrol edildi
- [ ] Gerekirse issue bağlantısı eklendi
```

## Review dili

İyi review, kişiyi değil değişikliği konuşur.

Örnek:

```text
Bu paragrafı biraz daha açık yazabilir miyiz?
```

```text
Dosya adı eğitimde kullandığımız adlandırmayla uyumlu görünüyor.
```
