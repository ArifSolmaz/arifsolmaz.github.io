# Katılımcılar

Her katılımcı bu klasöre kendi adıyla bir Markdown dosyası ekler.

Dosya adı örneği:

```text
ayse-yilmaz.md
```

İçerik örneği:

```md
# Ayşe Yılmaz

- İlgi alanım: dijital arşiv
- GitHub’dan beklentim: ekip çalışmasını daha düzenli yapmak
- Bugün öğrendiğim ilk kavram: branch
```
