In your screenshot, Tek Kullanımlık Parola reverted to -. This happens when RustDesk Service stops or you opened the portable .exe from Downloads instead of the installed service. Run this 1-click Admin PowerShell fix:

Cause B: Fortinet Blocked Port 21116 Relay DPI Heartbeat Drop

Enable "Doğrudan IP erişimi" (Direct IP Access)

When the campus Fortinet firewall blocks RustDesk's public coordination server (`port 21116`), the bottom bar turns red (Hazır değil). Enabling Direct IP Access makes RustDesk listen directly on local TCP port 21118 with zero internet relay required:

  1. Click 🔧 Ayarlar (Settings) at the top of RustDesk → Güvenlik (Security).
  2. Click Güvenlik ayarlarının kilidini aç (Unlock security settings).
  3. Under Parola, verify your Kalıcı parola (Permanent password) is set.
  4. Scroll down to Doğrudan IP erişimi and check Doğrudan IP erişimini etkinleştir (default port 21118).
Why this wins: Even if RustDesk shows a red dot forever, Cloudflare tunnels straight into localhost:21118!
Step 2 • Run on Campus PC PowerShell Uses TCP 443 (--protocol http2)

1-Click Campus Tunnel Launcher Script

Downloads cloudflared.exe from GitHub (unblocked), disables Windows AC sleep, ensures RustDesk service is running, and tunnels tcp://localhost:21118 over HTTP/2.

Campus PC PowerShell 
# 1. Prevent Sleep & Ensure RustDesk Service is Running
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
Set-Service -Name "RustDesk" -StartupType Automatic -ErrorAction SilentlyContinue
Start-Service -Name "RustDesk" -ErrorAction SilentlyContinue

# 2. Download cloudflared from GitHub if not present
if (-not (Test-Path "$HOME\cloudflared.exe")) {
    Invoke-WebRequest -Uri "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe" -OutFile "$HOME\cloudflared.exe"
}

# 3. Launch Outbound HTTPS/HTTP2 Tunnel for RustDesk Direct IP (Port 21118)
& "$HOME\cloudflared.exe" tunnel --url tcp://localhost:21118 --protocol http2
